## Overview
**Web-Blog-App--Project** is asimple web application built with Node.js, EJS, and custom CSS.
It allows users to create, manage, and explore blog posts across different categories such as Education, Motivation, and Poem.

## Features
- ✍️ Create, edit, and delete blog posts.
- 📂 Categorized posts (Education, Motivation, Poem).
- 🔍 View individual blog posts in detail.
- 🖼 Clean UI with custom styling.

## Getting Started

### Prerequisites
Ensure you have the following installed on your machine:  
- **Node.js** (v14 or higher)  
- **npm** (Node Package Manager)  

### Installation

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/Sufiana-A/Web-Blog-App---project.git
```
Navigate to the project directory
```bash
cd Web-Blog-App---project
```
Install dependencies
```bash
npm install
```
Or
```bash
npm i
```
---

## Usage

Run the project locally with:

```bash
node index.js
```

Then open your browser and navigate to:
👉 http://localhost:3000
